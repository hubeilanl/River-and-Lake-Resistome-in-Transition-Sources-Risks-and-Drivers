# Metagenomic workflows

The subdirectories contain the study-specific batch scripts and post-processing
code for:

1. read trimming with Trimmomatic;
2. ARG quantification with ARGs-OAP;
3. taxonomic profiling with Kraken2 and Bracken;
4. assembly with MEGAHIT;
5. binning, bin refinement, MAG quality control and GTDB-Tk classification;
6. ARG and MGE annotation with DIAMOND;
7. consensus plasmid prediction;
8. ARG sequence phylogenies;
9. MGE database construction and quantification; and
10. fecal-marker quantification with CoverM.
